# MH Plugin Store

Public, CDN-friendly mirror of the MH Manager plugin repository.

The main `MH-Manager` repo is private, so this dedicated public repo hosts the
plugin artifacts. Everything is served through the **jsDelivr** CDN
(`cdn.jsdelivr.net`) so unauthenticated clients can fetch `index.json`, `.mhmp`
packages, and icons quickly and reliably.

## Layout

```
plugins/repo/index.json            <- store index (fetch this first)
plugins/<plugin-id>/latest/*.mhmp  <- signed plugin packages
plugins/<plugin-id>/latest/icon.png
plugins/<plugin-id>/latest/metadata.json
```

## CDN URLs

- Index:  https://cdn.jsdelivr.net/gh/sketchnoobdeveloper/MH-Plugin-Store@main/plugins/repo/index.json
- Package: https://cdn.jsdelivr.net/gh/sketchnoobdeveloper/MH-Plugin-Store@main/plugins/<plugin-id>/latest/<file>.mhmp
- Icon:    https://cdn.jsdelivr.net/gh/sketchnoobdeveloper/MH-Plugin-Store@main/plugins/<plugin-id>/latest/icon.png

## Updating

Content is generated by the MH-Manager CI pipeline (`plugin-publish.yml`) and
mirrored here. Do not edit files directly — regenerate from
`tools/make-index.py` in the MH-Manager repo instead.
